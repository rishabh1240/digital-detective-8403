## Running the Number Converter

The number converter is available inside the `mission-05-numbers-data` folder.

To run the program:

1. Open Terminal in the repository's root directory.
2. Navigate to the Mission 05 folder:

   ```bash
   cd mission-05-numbers-data
   ```

3. Run the Python program:

   ```bash
   python3 number_converter.py
   ```

4. Enter a positive decimal number when prompted.

5. The program displays its Binary and Hexadecimal representations.

The program uses Python's built-in `bin()` and `hex()` functions for number conversion.

## My Learning

During this assignment, I developed practical knowledge of computers, programming, operating systems and version control.

1. **Computer Basics and Operating Systems:** I learned how computers process information using the IPOS cycle (Input, Processing, Output and Storage). I explored hardware and software components and understood operating-system responsibilities such as process management, memory management, device management, file management and security.

2. **Terminal and File Management:** I learned to navigate directories, create folders and files, copy and rename files, inspect directory listings, understand command flags and use pipes. I also explored package managers and practised working with Terminal.

3. **Python Programming:** I created and executed simple Python programs and understood the difference between compilers and interpreters.

4. **Numbers and Data:** I practised converting numbers between decimal, binary and hexadecimal systems. I also built a Python number converter and explored character encoding using ASCII, UTF-8 and Python's `ord()` function.

5. **Git and GitHub:** I learned how version control works, how to check repository status, stage and commit changes, inspect commit history, create and switch branches, push changes and collaborate through Pull Requests.

6. **Computer Networking:** I explored LAN, MAN, WAN, DNS, routers, protocols, packet switching and client-server communication. I also practised using `ping` and `nslookup` to understand connectivity testing and DNS lookups.
