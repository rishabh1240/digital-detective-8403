# Mission 01 — Know Your Computer

## 1. Mission Title and Objective

**Mission:** Know Your Computer

The objective of this mission is to understand how a computer receives input, processes data, produces output, and stores information. It also focuses on identifying hardware, software, and computer-based systems used in everyday life.

## 2. Work Completed

### Task 1.1 — Trace One Activity Using IPOS

**Chosen Activity: Typing and Saving a Document on a MacBook**

| Stage | What happens in my example? | Hardware / Component |
|---|---|---|
| Input | I type text using the keyboard and give commands using the trackpad. | Keyboard and trackpad |
| Processing | The processor executes instructions from the text editor and processes the entered text using memory. | CPU and RAM |
| Output | The typed text appears on the laptop screen. | Display screen |
| Storage | When I save the document, the file is stored on the laptop's internal storage. | SSD |

**Explanation**

When I type a document, the keyboard sends input to the computer. The CPU processes this input with the help of RAM and the text editor. The processed information appears on the screen as output. When I save the document, it is stored permanently on the SSD.

This process demonstrates the four stages of IPOS: Input, Processing, Output, and Storage.

### Task 1.2 — Identify Hardware and Software

Hardware refers to the physical components of a computer that can be touched.

Software refers to programs and instructions that allow the computer to perform different tasks.

| Item / Software Name | Hardware or Software? | Software Type (if applicable) | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text and commands |
| Trackpad | Hardware | Not applicable | Used to move the pointer and select items |
| Antigravity IDE | Software | Application Software | Used for writing and editing code and documents |
| SSD | Hardware | Not applicable | Stores files, applications, and system data |
| macOS | Software | Operating System | Manages computer hardware, software, and resources |
| Display Screen | Hardware | Not applicable | Displays text, images, and videos |

**Explanation**

Hardware and software work together to make a computer functional. Hardware performs physical operations, while software provides instructions to perform tasks.

Operating system software manages computer resources, application software helps users perform specific activities, and utility software helps maintain and manage the computer.

### Task 1.3 — Computer Systems Around You

Computer-based systems are used in many everyday activities apart from laptops and mobile phones.

| System | Main Purpose | One Input | One Output |
|---|---|---|---|
| ATM | Allows users to withdraw cash and perform banking transactions | PIN entered using keypad | Cash dispensed |
| Smart TV | Displays television programmes and online content | Remote control command | Video displayed on screen |
| Traffic Signal | Controls traffic movement at road intersections | Signal from a traffic sensor | Red, yellow, or green traffic light |

**Explanation**

**1. ATM:** An Automated Teller Machine accepts user input such as a PIN and transaction selection, processes the request, and dispenses cash or displays transaction information.

**2. Smart TV:** A smart television receives commands through a remote control, processes them, and displays the selected content on its screen.

**3. Traffic Signal:** An automated traffic signal uses a controller and, in some systems, traffic sensors to manage the movement of vehicles by displaying red, yellow, and green lights.

These examples show how computer-based systems use input, processing, and output to perform everyday tasks.
